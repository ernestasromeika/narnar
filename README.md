# NarNar

A little trade. A place to call home.

**[Play NarNar](https://ernestasromeika.github.io/narnar/)**

A single-player, cozy 2.5D trading adventure on Northlight Isle. You are a small penguin with a red scarf, six pockets, a pomegranate, and the wonderfully unreasonable ambition of trading your way to a seaside house.

## The adventure

- An open island with six districts, 20 neighbours, and 28 story trades across five chapters.
- An orthographic 3D world with soft shadows, rounded characters, coastal water, swaying boats, seabirds, orchards, timber houses, and a working lighthouse.
- Six inventory slots, stackable gathering items, and a travel trunk that prevents inventory dead ends.
- Fishing, foraging, a three-part wind-chime melody, 12 collectible postcards, and an optional sea-glass scarf quest.
- Four animated, skippable in-engine story sequences: arrival, first trade, lighthouse restoration, and retirement.
- Procedural music, quiet character voices, waves, footsteps, and distinct event sounds. Independent music and sound controls.
- Browser autosaves, manual saves, validated JSON save import/export, keyboard, mouse, and touch controls.
- Intended for a leisurely 30–60 minute first visit. Reading, exploring, running, and using hints change the duration; this is a design target, not a timed gate or measured playtest result.

## Controls

| Action                            | Control                                               |
| --------------------------------- | ----------------------------------------------------- |
| Walk                              | WASD / arrows / touch arrows                          |
| Run                               | Hold Shift / touch Run                                |
| Click to move                     | Click the ground; the penguin routes around obstacles |
| Talk, collect, fish, play a chime | E / Interact                                          |
| Map                               | M                                                     |
| Journal / travel trunk            | J                                                     |
| Hint                              | H / A little nudge                                    |
| Inspect a pocket                  | 1–6 / click the item                                  |
| Pause / close / skip a scene      | Escape                                                |
| Advance a story shot              | Enter / Space / Continue                              |
| Fishing                           | E / Space / Reel gently                               |

The game has no combat, death, energy meter, ads, accounts, or purchases. Your neighbours will wait. You can keep exploring after retirement.

## Saves

Progress is stored in `localStorage` under `narnar-save-v1` every 15 seconds and after meaningful actions. It belongs to this browser and site origin. Download a backup in **Pause → Download save** to move devices or protect against clearing browser data. Imported files are validated before replacing progress, and the game asks before replacement. No save data is sent to a server.

## Development

Requires Node.js 22.13 or later and npm.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Production is a static Vite build in `dist/`. GitHub Actions builds and deploys each push to `main` using GitHub Pages. The relative asset base supports project Pages URLs. Google Fonts enhances typography; system fonts are the fallback. All 3D scenery, character models, effects, and audio are generated by the game itself. No paid services or API keys are required.

## Source guide

- `src/content.js`: neighbours, story exchanges, items, collectibles, and landmarks.
- `src/state.js`: inventory transactions and save validation.
- `src/world.js`: geometry, lighting, animation, collision, and click-to-move routing.
- `src/main.js`: interface, controls, interactions, journal, save files, and scene flow.
- `src/audio.js`: synthesized ambience, music, and effects.
- `src/scenes.js`: cinematic shots and narration.
- `src/style.css`: desktop and touch layouts.

Built with Three.js and Vite. The original Sites scaffold dependencies are retained; the deployed game is entirely static and has no server runtime.

## Verification

The production build is checked, and ad hoc Node simulations exercised the 28-trade path, prerequisite failures, six-pocket limit, storage recovery, save round trips, malformed save rejection, retirement, main dialogue handlers, journal, map, and settings. A walkability flood-fill verified access to every interactive entity. These checks use a renderer stub and DOM simulation; they do not replace a real GPU/browser playtest or a measured 30–60 minute user session. Optional WebMCP read/save handlers are feature-detected; no supported live WebMCP browser was available for contract verification.
